Grid systems still matter because human attention is not infinite

Why the 12-column grid, born in 1961, remains the most powerful design constraint in 2026.

Press N for speaker notes - Arrow keys to navigate
The core argument

A grid is a constraint that creates freedom

  • Without a grid, every decision is ad hoc, every alignment is arbitrary, every spacing is a debate
  • With a grid, 80% of layout decisions are pre-made, and the remaining 20% get deliberate attention
  • The grid is not a limitation. It is a budget for creative attention
Two design philosophies

Improvised layout vs gridded layout

Improvised

  • Every slide is a new design problem
  • Alignment is eyeballed, not measured
  • Spacing varies by feel, not by system
  • Inconsistency reads as unprofessional
  • Time spent on layout, not on content

Gridded

  • One grid system, applied to every slide
  • Alignment is structural, not decorative
  • Spacing follows a defined scale
  • Consistency reads as intentional
  • Time spent on content, not on layout
The evidence
8pt

the base unit that governs every spacing decision in a disciplined system

All padding, margins, gaps, and type sizes are multiples of 8. No exceptions.
What to do Monday

Stop improvising. Start gridding.

Pick a 12-column grid. Choose an 8pt spacing scale. Apply them to every slide. Spend the time you save on the content, not the layout.
