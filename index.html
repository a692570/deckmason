Why DeckMason

Other AI slide tools generate pretty pictures. DeckMason generates decks with narrative structure, color theory validation, and quality guardrails that fight AI slop at the generation layer.

Pyramid Principle storytelling

Assertion-evidence headings, thesis framing, contrast beats. Every slide ladders up to a single argument. Not bullet lists.

Color theory validation

60-30-10 distribution, WCAG 4.5:1 contrast, 13-rung lightness ladder. Validated per slide, not just at theme level.

31 curated themes

11 original plus 20 extended, each with classified harmony, temperature, and 60-30-10 metadata. From Modern SaaS to Brutalist to Swiss Modern.

PPT import

Import existing .pptx files, extract content and theme, rebuild as polished HTML. Your old decks get the DeckMason treatment.

Visual preview mode

Generate 3 cover slide previews in different themes before committing. Pick visually instead of describing aesthetics in words.

GSAP animations

Optional GSAP-powered entrance and reveal animations with prefers-reduced-motion fallbacks. Subtle, not theatrical.

How it works

Your agent reads the skill, follows the 6-phase workflow, and writes real HTML files to disk. No chat window paste jobs.

Point your agent at SKILL.md

Clone the repo or run npx deckmason init. Tell your agent to build a deck. It reads the 198-line entry point and loads phase details on demand.

Scope and structure

Visual preview or 4 text questions. Then Pyramid Principle structure: one thesis, 3 to 5 supporting arguments, evidence per slide. Assertion-evidence headings, not topic labels.

Generate and polish

HTML with Canvas Scale Architecture, quality guardrails, AI Tells checklist, Designer's Eye critique. Export to PPTX or PDF. Ship it.

FAQ

What coding agents does DeckMason work with?

Any agent that can read files and run scripts: Claude Code, Cursor, Codex CLI, Windsurf, Aider, OpenClaw, and others. The agent reads SKILL.md and follows the workflow. No special plugins or integrations needed.

Do I need API keys or cloud services?

No. DeckMason runs entirely locally. Your coding agent uses its own LLM to generate the deck content. The only external dependency is Google Fonts for typography, loaded via CDN link in the generated HTML.

Can I import existing PowerPoint files?

Yes. Run python3 scripts/pptx_import.py input.pptx to extract slide content, theme colors, and fonts into a structured JSON file. Your agent then maps the content to DeckMason slide types and rebuilds it as a polished HTML deck.

Can I export to PowerPoint or PDF?

Yes. PPTX export uses python-pptx (Path A, image-based) or pptxgenjs (Path B, editable text boxes). PDF export uses headless Chrome or Playwright. Both are documented in the reference files.

How does the visual preview mode work?

Run python3 scripts/preview_themes.py "Your Topic" to generate 3 cover slide previews in different themes (dark, light, bold). Open the 3 HTML files, pick the direction you like, and tell your agent which one to use for the full deck.

Can I match my existing brand?

Yes. Brand import extracts colors and fonts from a PPTX file (theme1.xml), a website URL (CSS variables), or a brand guidelines PDF. Your agent applies the extracted brand tokens to the generated deck.

How does progressive disclosure work?

SKILL.md is a 198-line entry point. The 6 phases have dedicated reference files in the references/ directory. Your agent loads only the file for the phase it is working on, instead of loading all 1,572 lines of detail every time. This saves context tokens and speeds up generation.

How do I install it?

Three options: git clone https://github.com/a692570/deckmason.git, npx deckmason init, or npm install -g deckmason. For Claude Code, copy the repo to your skills directory. Full instructions are in the README.

Is it free?

Yes. MIT licensed, no cost, no sign-up, no API keys. The only cost is whatever your coding agent's LLM provider charges for token usage during generation.
