Brief, structure, outline, HTML, images, polish, export. Contrast and layout rules get checked at every phase along the way.

03

You get a finished deck

Every deck passes the same checks. Contrast, structure, one idea per slide. Every time.

Guardrails

Rules the agent cannot skip

  • One idea per slide. Two ideas means two slides.
  • No three same-weight slides in a row. Hero and non-hero layouts alternate on purpose.
  • No fabricated statistics. The Data Slop Rule: never add a number the user didn't provide.
  • No overflow:hidden to hide overflow. If content doesn't fit, the slide splits.
  • Title at least 2.5x the body size, 3x is the target.
  • Every animated deck ships a reduced-motion path.
  • Banned word list enforced at generation time: unleash, elevate, seamless, transformative, and the rest.

FAQ

What agents does this work with?

Claude Code, Cursor, Codex CLI, Windsurf, Aider, OpenClaw, or any agent that reads files and runs scripts.

Do I need API keys or a cloud account?

No. Everything runs through your existing coding agent and local scripts, without any additional API keys or a cloud dependency.

Can I import an existing PowerPoint?

pptx_import.py extracts slide content, images, theme colors, and fonts into a JSON file your agent maps onto DeckMason's slide types.

Can I export back to PowerPoint or PDF?

Yes, both. PPTX via python-pptx or pptxgenjs, PDF via browser print or headless Chrome.

How do I match our brand?

Extract a theme from a PPTX, a website URL, or a brand guidelines PDF instead of picking a preset.

What is visual preview mode?

Instead of four text questions, generate three quick preview slides in different themes and pick a direction by eye.

Why is SKILL.md short if the workflow has 7 phases?

Progressive disclosure. SKILL.md is the entry point; each phase's detail lives in references/ and loads only when the agent needs it.

Is it free?

Yes. MIT licensed, free for personal and commercial use.
