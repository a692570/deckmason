A pasted prompt cannot keep a grid.

Most agent decks fail the same three ways: topic-label headings, broken contrast, five slides that weigh the same. DeckMason makes those hard rules, not reminders.

The story is a thesis, not a table of contents

Phase 1 encodes the Pyramid Principle. Every heading is an assertion. If the title is a topic label, the slide has no point and gets rewritten.

Color is a ratio, then a check

Each theme ships with harmony, temperature, and a 60-30-10 split. Phase 5 checks contrast at 4.5:1, a 13-rung lightness ladder, and saturation budget before delivery.

The output is a file, not a chat blob

Self contained HTML with 1920 by 1080 canvas math, speaker notes, and keyboard nav. Export with python3 scripts/pptx_export.py or headless Chrome for PDF.

Your existing deck is source material

deckmason import company-deck.pptx extracts slides, notes, theme colors, and fonts to JSON. The agent rebuilds under the same guardrails. Brand import also reads a website or a brand PDF.

The skill refuses invented proof

Data Slop Rule: no statistic the user did not provide. Banned words list. 30 percent copy cut. One idea per slide. Reduced motion path on every animated deck.

A prompt cannot enforce contrast. A skill file can.

Three commands. Then you talk to the agent.

The CLI copies the skill. The agent reads SKILL.md and loads each phase file only when it reaches that phase.

01

Install locally

Run npx deckmason init. Default path is ~/.claude/skills/deckmason. Or clone the repo. Or npm install -g deckmason.

02

Pick a direction with your eyes

Run deckmason preview "Your Topic". You get three one-slide HTML files: Deep Space, Modern SaaS, Bold Signal. Open them, pick one, tell the agent. Text questions exist if you prefer words.

03

Ask for the deck

Point the agent at SKILL.md. It briefs, structures, outlines, writes HTML, checks itself, then exports if you asked. Specialized modes (cinematic 22s, Swiss strict, editorial web, brand import) load only when requested.

$ npx deckmason init
$ deckmason themes
$ deckmason preview "Series A pitch"
$ deckmason import company-deck.pptx

What the agent is not allowed to skip.

From SKILL.md and references/quality-guardrails.md. These are gates, not style tips.

  • Pre-flight scoping before a single slide: preview or four text questions.
  • One idea per slide. Two ideas means two slides.
  • No overflow:hidden to hide overflow. Split the slide.
  • Title at least 2.5x body. Target 3x.
  • Hero and non-hero alternate. No three same-weight slides in a row.
  • N toggles speaker notes on every HTML deck.
  • Self-check checklist before delivery: narrative, visual, color, content, technical, taste.

Questions people actually ask.

Answers from the README, CLI, and skill files. Nothing invented for this page.

What agents does this work with?

Any agent that can read files and run scripts: Claude Code, Cursor, Codex CLI, Windsurf, Aider, OpenClaw. No plugin. The agent reads SKILL.md and follows the workflow.

Do I need API keys or a cloud account?

No. DeckMason runs locally. Your agent uses its own model. The generated HTML loads Google Fonts from a CDN. That is the only network call in a finished deck.

Can I import an existing PowerPoint?

Yes. deckmason import file.pptx or python3 scripts/pptx_import.py file.pptx writes JSON with titles, body, images, notes, theme colors, and fonts. The agent maps those slides onto DeckMason types and rebuilds them.

Can I export back to PowerPoint or PDF?

Yes. Path A is python3 scripts/pptx_export.py presentation.html --output presentation.pptx (image based, python-pptx). Path B is pptxgenjs and produces editable text boxes. PDF is headless Chrome or Playwright.

How do I match our brand?

Brand import reads theme1.xml from a PPTX, CSS variables from a URL, or hex and type rules from a brand PDF. The agent applies those tokens instead of a preset. Or pick one of the 31 presets, plus Kami Warm Editorial for print-like decks.

What is visual preview mode?

deckmason preview "Your Topic" writes three single-slide HTML files: Deep Space, Modern SaaS, Bold Signal. You pick with your eyes. The four text questions stay as a fallback.

Why is SKILL.md short if the workflow is long?

Progressive disclosure. SKILL.md is the entry point, about 200 lines. Each phase lives in references/. The agent loads only the file for the phase it is in. The original single file was 1,195 lines.

Is it free?

Yes. MIT license. No signup. The only cost is the tokens your agent already spends when it writes the deck.
