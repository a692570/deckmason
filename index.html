02 / WHY

Not another slide generator

Other tools make pretty pictures. DeckMason enforces narrative structure, validates color theory per slide, and fights AI slop at the generation layer.

storytelling

Pyramid Principle, not bullet lists

Every deck starts with a thesis. Each slide is an assertion-evidence heading that ladders up to the thesis. Contrast beats toggle between "what is" and "what could be" throughout. This is the storytelling framework McKinsey uses, encoded as a workflow your agent follows.

color science
6030-10

Color distribution validated per slide. WCAG 4.5:1 contrast on all text pairs. 13-rung lightness ladder with collision detection. Saturation discipline enforced. Not just a palette pick.

themes
31 curated

11 original plus 20 extended. Each ships with classified harmony, temperature, and 60-30-10 metadata. From Modern SaaS to Brutalist to Swiss Modern to Deep Space.

imports

PPT import

Drop a .pptx, extract content and theme, rebuild as polished HTML with quality guardrails applied.

Visual preview

Generate 3 cover slide previews in different themes before committing. Pick visually, not verbally.

Brand import

Extract colors and fonts from a PPTX, website URL, or brand PDF. Your deck matches your brand.

animation

GSAP, with fallbacks

Optional GSAP-powered entrance and reveal animations. Every pattern has a prefers-reduced-motion fallback. Subtle, not theatrical.

guardrails

Anti-slop, built in

Banned words list (no "unleash", "elevate", "seamless"). Data Slop Rule: never invent statistics. 30% Copy Cut Rule. AI Tells checklist before delivery. Designer's Eye critique.

03 / WORKFLOW

How it works

Your agent reads the skill, follows the 6-phase workflow, and writes real HTML files to disk.

1

Point your agent at SKILL.md

Clone the repo or run npx deckmason init. Tell your agent to build a deck. It reads the 198-line entry point and loads phase details on demand, not all at once.

2

Scope and structure

Visual preview or 4 text questions. Then Pyramid Principle: one thesis, 3 to 5 supporting arguments, evidence per slide. Assertion-evidence headings, not topic labels.

3

Generate and polish

HTML with Canvas Scale Architecture, quality guardrails, AI Tells checklist, Designer's Eye critique. Export to PPTX or PDF. Ship it.

07 / FAQ

Questions

What coding agents does this work with?

Any agent that can read files and run scripts: Claude Code, Cursor, Codex CLI, Windsurf, Aider, and others. The agent reads SKILL.md and follows the workflow. No plugins needed.

Do I need API keys or cloud services?

No. DeckMason runs entirely locally. Your agent uses its own LLM to generate content. The only external dependency is Google Fonts, loaded via CDN in the generated HTML.

Can I import existing PowerPoint files?

Yes. Run python3 scripts/pptx_import.py input.pptx to extract slide content, theme colors, and fonts into JSON. Your agent maps the content to DeckMason slide types and rebuilds it as HTML.

Can I export to PowerPoint or PDF?

Yes. PPTX export uses python-pptx (Path A, image-based) or pptxgenjs (Path B, editable text boxes). PDF export uses headless Chrome or Playwright.

How does visual preview mode work?

Run python3 scripts/preview_themes.py "Your Topic" to generate 3 cover slide previews in different themes. Open the files, pick a direction, and tell your agent which one to use.

Can I match my existing brand?

Yes. Brand import extracts colors and fonts from a PPTX (theme1.xml), a website URL (CSS variables), or a brand guidelines PDF. Your agent applies the extracted tokens to the deck.

How does progressive disclosure work?

SKILL.md is a 198-line entry point. Each phase has a reference file in references/. Your agent loads only the file for the phase it is working on, instead of all 1,572 lines every time. Saves tokens, speeds up generation.

How do I install it?

Three options: git clone https://github.com/a692570/deckmason.git, npx deckmason init, or npm install -g deckmason. Full instructions in the README.

Is it free?

Yes. MIT licensed. No cost, no sign-up, no API keys. The only cost is your agent's LLM token usage during generation.
